## 🛠️ Features (ප්‍රධාන විශේෂාංග)

මෙම Bot හරහා ඔබට පහත සඳහන් දේවල් ඇතුළුව තවත් බොහෝ දේ කරගත හැක:

- ⚡ **වේගවත් ක්‍රියාකාරිත්වය** (Fast Response)
- 🎵 **Song & Video Downloads** (යූටියුබ්, ෆේස්බුක්, ටික්ටොක් හරහා)
- 🖼️ **Sticker Maker** (පින්තූර සහ වීඩියෝ වලින් ස්ටිකර් සෑදීම)
- 🛡️ **Group Management** (Anti-link, Welcome/Goodbye messages, Auto-kick)
- 🎮 **Fun Commands** (විවිධ ක්‍රීඩා සහ විනෝදාත්මක දේවල්)
- ⚙️ **Easy Configuration** (ඔබට අවශ්‍ය පරිදි සැකසුම් වෙනස් කර ගැනීමේ හැකියාව)

## 💻 Local Setup (ඔබගේ පරිගණකයේ ධාවනය කිරීමට)

ඔබට මෙය ඔබේ පරිගණකයේ (PC/VPS) ධාවනය කිරීමට අවශ්‍ය නම් පහත පියවර අනුගමනය කරන්න. ඔබගේ පරිගණකයේ `Node.js` සහ `Git` Install කර තිබිය යුතුය.

```bash
# 1. Repository එක Clone කරගන්න
git clone [https://github.com/ThanujaDilshan-LK/QUEENHANSI-MD.git](https://github.com/ThanujaDilshan-LK/QUEENHANSI-MD.git)

# 2. Folder එකට යන්න
cd QUEENHANSI-MD

# 3. අවශ්‍ය Packages Install කරන්න
npm install

# 4. Bot එක Run කරන්න
npm start
